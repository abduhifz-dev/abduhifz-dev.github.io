      05About

      One engineer, the whole stack.

      I'm a software and systems engineer from Islamabad. I started out building Android apps in Java with MVVM, Clean Architecture, Hilt and Coroutines, and desktop software in Java Swing and C++/Qt, at ProIT and SKYNEX and for clients on Fiverr and Upwork.

      Today I run CorePilot, where I bring that same discipline to everything a drone program needs: flight-controller boards, custom ArduPilot firmware, encrypted links, ground stations and log tools. I also build desktop apps, Flutter apps, and AI models that run on the user's own hardware.

      • End to endHardware, firmware, apps and docs, with one person accountable for how they fit together.
      • Private by defaultOffline-first apps, encrypted files and links, hardened release builds.
      • Measured, not claimedBenchmarks that include the failures, ERC and DRC reports, SITL tests.
